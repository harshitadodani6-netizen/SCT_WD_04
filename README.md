# SkillCraft Technology - Task 4

## 📌 Project Overview
This repository contains **Task 4** completed as part of my internship at **SkillCraft Technology**. The project is a **To-Do List Web Application** that helps users organize and manage their daily tasks efficiently. Users can add, mark as completed, and delete tasks through a simple and interactive interface.

## 🚀 Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and responsive user interface
- Fast and easy task management

##  Technologies Used
- HTML5
- CSS3
- JavaScript
